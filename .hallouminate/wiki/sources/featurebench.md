# FeatureBench: Benchmarking Agentic Coding for Complex Feature Development

FeatureBench: Benchmarking Agentic Coding for Complex Feature Development evaluates agentic coding through feature-level development tasks.
Qixing Zhou and coauthors publish this research paper in February 2026. This source entry is verified on 2026-09-29.
Canonical source: [FeatureBench: Benchmarking Agentic Coding for Complex Feature Development](https://arxiv.org/html/2602.10975v1).

## FeatureBench feature-development scope

FeatureBench measures complex feature development, not only issue repair.
Level 1 restores feature implementations. Level 2 develops from scaffolding.
Table 3 reports Level-1 averages of 790.2 solution lines, 15.7 files, and 29.2 functions.
These are not Lite-only statistics.
Solution-line counts are not comparable to added/deleted-line counts without qualification.

The paper supports the [Gin comparison](../benchmark-gin-render-context.md), not a measured difficulty ranking.
