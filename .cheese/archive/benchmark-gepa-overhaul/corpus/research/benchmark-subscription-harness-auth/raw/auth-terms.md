# Raw source notes: subscription auth for headless Claude Code / Codex harness
Accessed: 2026-10-03. All excerpts are untrusted fetched data.

## Claude Code authentication — https://code.claude.com/docs/en/authentication (accessed 2026-10-03)
- setup-token: "For CI pipelines, scripts, or other environments where interactive browser login isn't available, generate a one-year OAuth token with `claude setup-token`"
- "It does not save the token anywhere; copy it and set it as the `CLAUDE_CODE_OAUTH_TOKEN` environment variable"
- "This token authenticates with your Claude subscription and requires a Pro, Max, Team, or Enterprise plan. It can only make model requests, so it can't establish Remote Control sessions or fetch claude.ai connectors. MCP servers you configure locally still work."
- "Bare mode does not read `CLAUDE_CODE_OAUTH_TOKEN`. If your script passes `--bare`, authenticate with `ANTHROPIC_API_KEY` or an `apiKeyHelper` instead."
- Precedence: 1 cloud provider, 2 ANTHROPIC_AUTH_TOKEN, 3 ANTHROPIC_API_KEY ("In non-interactive mode (-p), the key is always used when present"), 4 apiKeyHelper, 5 CLAUDE_CODE_OAUTH_TOKEN ("A long-lived OAuth token generated by claude setup-token. Use this for CI pipelines and scripts where browser login isn't available."), 6 profiles, 7 subscription OAuth from /login.
- Linux storage: "On Linux, credentials are stored in `~/.claude/.credentials.json` with file mode `0600`."
- CLAUDE_CONFIG_DIR: "Claude Code keeps the `.credentials.json` file under that directory instead"
- Containers: "If your browser shows a login code instead of redirecting back ... paste it into the terminal ... common in WSL2, SSH sessions, and containers."
- Expiry: "When the login you created with /login is within three days of expiring ... `Your login expires in 3 days`"; "Once the stored login expires and can't be refreshed, each model request fails with `Login expired · Please run /login`"
- (No statement found on refresh-token rotation / concurrent-copy invalidation for claude.ai logins.) Console profile: "Claude Code refreshes the profile's login automatically, and when refresh fails, requests fail with Anthropic profile login expired"

## Headless — https://code.claude.com/docs/en/headless (accessed 2026-10-03)
- "Set `ANTHROPIC_API_KEY` before running it, because bare mode doesn't use your subscription login"
- "In bare mode, Claude Code never reads OAuth credentials or the system keychain."
- "`--bare` is the recommended mode for scripted and SDK calls, and will become the default for `-p` in a future release."
- "With `--output-format json`, the response payload includes `total_cost_usd` and a per-model cost breakdown ... Both figures are client-side estimates and can differ from your actual bill."
- "The last line of the stream is a `result` message with the final response text, cost, and session metadata."
- system/api_retry event `error` categories include `rate_limit`, `billing_error`, `authentication_failed`, `account_on_hold`.
- "Claude Code exits with code 0 on success and a non-zero code when the run fails ... such as missing authentication, Claude Code prints the failure as the result on stdout."

## Errors — https://code.claude.com/docs/en/errors (.md, accessed 2026-10-03)
- "You've hit your session limit · resets 3:45pm / You've hit your weekly limit · resets Mon 12:00am / You've hit your Opus limit · resets 3:45pm / You've hit your Sonnet limit · resets 3:45pm"
- "The session and weekly limits are shared across all models ... The Opus and Sonnet limits each apply only to requests to that model family"
- "Usage counts against the session and weekly allowances at the same time. A single burst of heavy activity, such as a large workflow fanout, can exhaust the weekly allowance before the session window resets."
- "Run `/usage` to see your plan limits and when they reset"; warning "You've used 85% of your session limit"
- Login expired: "Claude Code tried to renew your saved claude.ai login and the OAuth service rejected the stored refresh token, so Claude Code cleared the saved credentials." -p text: "Failed to authenticate: OAuth session expired and could not be refreshed" code `authentication_failed`.
- Refresh lock: "Another Claude Code process on the same machine held the shared refresh lock" ; -p: "Failed to refresh OAuth token: another Claude Code process is refreshing it or exited mid-refresh..." code `server_error`.
- Rotation hint: "When a classifier request fails because your OAuth token expired or was rotated by another session, Claude Code refreshes the token and retries"
- CLAUDE_CODE_OAUTH_TOKEN: "If you authenticate with a long-lived token in CLAUDE_CODE_OAUTH_TOKEN, you see the same messages when that token expires or is revoked."
- "For automation that can't sign in interactively, authenticate with ANTHROPIC_API_KEY or generate a long-lived token with claude setup-token."
