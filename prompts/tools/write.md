create_file is only for paths that do not exist; to replace an existing file, use {op: "replace", start: 1, end: N, content} with its tag. Cover the whole affected construct in one edit: obsolete locals, comments, and the delimiters around an insertion (never insert inside a grouped declaration). Edit after a tagged read or search. `tilth_read` prints `[path#TAG]` above `N:content`; `tilth_search` shows `path#TAG` too. Copy the TAG and shown 1-based integer lines; never invent either. The result returns the file's new `[path#TAG]` and the changed line ranges; lines you wrote or already read stay editable from that tag with no read; read a range to edit any other line. `edits` contains `{path, tag?, ops}` sections; omit tag only for a new or untaggable file. Ops: replace_text uses {old,new}, must match once (all:true replaces every exact match; count:N requires exactly N; all/count match against the version you saw; every match must be on shown lines); rewrite uses {pattern,rewrite,count?} to replace outermost, non-overlapping ast-grep matches ($X, $$$X) in the seen version; nested matches are skipped and count:N counts selected matches; every line a match spans must be shown, e.g. {op: "rewrite", pattern: "$R.Render($W)", rewrite: "$R.Render(context.Background(), $W)"}; create_file uses {content}; replace/delete use `{start,end}`; insert_before/after use `{line}`; prepend/append; block ops use `{at}`; delete_file; move_file. Block ops span the tree-sitter definition at a line or `#symbol`. In JSON strings write a tab as `\t` and a newline as `\n`, never the raw character (literal controls fail before the server): {old: "\tfoo()", new: "\tbar()\n"}. Sections are independent. Example: tilth_write(edits: [{path: "a.rs", tag: "1A2B", ops: [{op: "replace_text", old: "let x = 1;", new: "let y = 2;"}]}], cwd: "/abs/repo").
